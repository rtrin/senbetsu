With the Bring-Your-Own-Key (BYOK) plan, you get unlimited AI tab grouping powered directly by your own OpenAI account, meaning your data never passes through our proxy. 

Here is how to get set up in two quick steps:

### 1. Generate your OpenAI API Key
1. Go to [platform.openai.com/api-keys](https://platform.openai.com/api-keys) and log in (or create an account if you don't have one).
2. Click **"+ Create new secret key"**. 
3. Give it a memorable name like "Senbetsu Extension".
4. Copy the key immediately (it usually starts with `sk-...`). **You won't be able to see it again!**

*(Note: If this is a new OpenAI account, you'll need to add a few dollars of credit under the "Billing" section for the API to work. Tab grouping is incredibly cheap—you likely won't even spend $1 a month).*

### 2. Add it to Senbetsu
1. Click the **Senbetsu** icon in your Chrome toolbar.
2. Click the **Settings** tab.
3. Paste your new API key into the "OpenAI API Key" field and hit **Save**.
